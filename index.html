Campus life, all in one place.

Campus Life Planner helps students discover activities, find their community, and keep the events they care about together. Less searching through emails, more taking part in campus life.

Discover an event, bookmark it to My Events, and use RSVP to access registration when the organiser provides a link.

Built by Ismail

A student project for the Building Responsive UI assignment, made with vanilla HTML, CSS, and JavaScript.

GitHub ↗n.ismael@alustudent.com

This is a student prototype with sample events and organiser profiles. In the planned workflow, bookmarks are saved in this browser; they do not register you for an event. Shared campus data and organiser accounts require a backend. This project is not an official ALU service.
